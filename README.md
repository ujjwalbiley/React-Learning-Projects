## 💻 Getting Started

Follow these steps to run any project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/ujjwalbiley/React-Learning-Projects.git
```

### 2. Navigate to the Repository

```bash
cd React-Learning-Projects
```

### 3. Open a Specific Project

For example, to run the Theme Changer project:

```bash
cd themeChanger
```

You can replace `themeChanger` with any other project folder name.

### 4. Install Dependencies

```bash
npm install
```

### 5. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

**Note:** Some projects may have different setup requirements. Check their individual `package.json` files before running them.
